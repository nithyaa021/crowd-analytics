The pipeline

Six stages, one human gate

Each stage does one job and hands a specific artefact to the next. If a stage is vague, the next one produces slop — so the artefacts are the contract.

01 Idea Voice note
02 Research Structured brief
03 Copy Slide-by-slide
04 Visual Layout + direction
05 Assemble Editable file
06 Review Human, then export
01 3 min

Capture the raw idea

The founder records a 60-second voice note — messy, spoken, unedited. No template to fill. Constraints kill ideas before they exist.

Input Voice note, or 3 typed sentences
Output Raw transcript in a Notion inbox row
Notion Whisper / Otter Google Keep (fallback)

Why this tool: Notion is already the founder's notes app, so there is no new habit to build. Whisper runs free locally; Otter is the paid option if transcription accuracy matters (technical vocabulary).

02 6 min

Research and structure

A research prompt turns the transcript into a structured brief: the single claim, three to five supporting points, the counter-argument, and the specific number that makes it credible.

Input Raw transcript
Output One-page brief with a claim + evidence map
Claude Perplexity (sourcing)

Why this tool: Claude holds long context and follows structural instructions well. Perplexity does the live sourcing, because asking a model to invent a statistic is how brands get caught.

03 8 min

Write the slide-by-slide copy

One prompt produces the hook plus seven slides, each with a headline under 9 words and a body under 22 — hard limits, because they are what keep a slide readable on a phone.

Input Structured brief
Output JSON array of 8 slides with role + copy
Claude the founder's own voice samples

Why this tool: JSON output matters more than it sounds — it feeds stage 05 directly, so nobody re-types copy into a design file. Voice samples are pasted in so the output doesn't sound like a LinkedIn thought leader.

04 5 min

Generate visual direction

The same JSON gets a design brief attached: brand colours, type pairing, spacing rules, and the four slide templates (hook, point, proof, CTA). The model picks a template per slide and writes the layout instruction.

Input Slide JSON + brand token sheet
Output Per-slide template choice + image prompts
Claude Nano Banana / Ideogram (imagery)

Why this tool: A brand token sheet is the single highest leverage artefact here — colours and spacing written as variables stop the model from inventing a new palette on slide six.

05 10 min

Assemble an editable file

Three viable routes, in order of how much control the founder keeps. Pick by how often the design will need manual edits.

Route A · most control Canva template + bulk create

8 named frames, brand kit locked. Copy pasted by hand or via the Apps Script importer. Fully editable, zero lock-in.

Route B · best default Figma + variables

One component, 8 instances, text overrides driven by the JSON. Free tier is enough for one founder. Exports clean PNGs.

Route C · most automated HTML → PNG via n8n

A puppeteer step renders this page's own CSS at 1080×1350. Zero design tool, but edits mean editing code.

What I'd actually build: Route B. It is the only option where "make the third slide say something different" is a 10-second edit rather than a re-render.

06 6 min

Review, edit, export, schedule

The one stage that is deliberately manual. The founder reads every slide out loud, checks three things, fixes, exports, and schedules. Nothing publishes without a human tapping it.

Meta Business Suite Buffer n8n (optional auto-post)

Why keep this human: the cost of one wrong medical claim or one tone-deaf line is far higher than six minutes. Automate the assembly, never the judgement.

The stack

What I'd use, and what I'd refuse to use

Every row names the cheaper or more obvious alternative, because the interesting decision is usually what you don't adopt.

Stage Tool Why this one Rejected
Capture Notion + Whisper Already open daily; free, local transcription; no new app to remember. Notion AI (locked in, no better here)
Research ClaudePerplexity Claude for structure and long context; Perplexity for live citations so no stat is invented. ChatGPT for everything (one model, worse at both)
Copy Claude Best at following hard formatting limits (word counts) and returning clean JSON. Jasper / Copy.ai (subscription, generic voice)
Imagery IdeogramNano Banana Both render legible text when a slide needs a typographic hero image. Stock libraries (looks like everyone else's post)
Assembly FigmaCanva Figma for variables and precise control; Canva if the founder must edit without help. Photoshop (overkill), Midjourney (no layout)
Automation n8n Self-hostable and free, so the system survives if the founder stops paying. Make (task limits), Zapier (expensive at volume)
Publish Meta Business SuiteBuffer Native scheduling is free and does not throttle carousels. Auto-posting bots (account risk for marginal gain)
Deliberate omission: no full auto-posting. The last 90 seconds stay manual. A scheduled carousel that goes out unchecked is a reputational liability, and the marginal time saved is under two minutes.

Prompt pack

The three prompts that do the work

Copy these verbatim. The constraints are doing more work than the instructions — word limits are what stop a slide from becoming a paragraph.

Stage 02 · Research 
You are a content strategist for a veterinary care platform.

Here is a rough idea transcript: [PASTE TRANSCRIPT]

Produce a one-page brief with exactly these sections:
1. CLAIM — the single sentence the post argues. Max 18 words.
2. EVIDENCE — 3 to 5 supporting points. For each, mark [VERIFIED]
   if it needs a real source, or [OPINION] if it is a judgement call.
3. TENSION — the strongest counter-argument to the claim, in one line.
4. NUMBER — one specific, checkable number that would make this
   credible. If none exists, say "no defensible number available".
5. AUDIENCE — who this is for and what they fear.

Rules: no hedging language, no "in today's fast-paced world",
no em-dash-heavy influencer voice. Plain sentences.
Stage 03 · Copy 
Using this brief: [PASTE BRIEF]

Write an 8-slide Instagram carousel. Return only valid JSON, an array
of 8 objects, each with:
  "role": "hook" | "point" | "proof" | "cta"
  "headline": string, max 9 words, no period
  "body": string, max 22 words, max 2 sentences
  "kicker": string, 1-3 words, uppercase, or empty

Structural rules:
- Slide 1 is the hook. It must create discomfort or curiosity.
  It must NOT describe what the post is about.
- Slides 2-6 are points. Each stands alone if screenshotted.
- Slide 7 is the proof or the "what to actually do" step.
- Slide 8 is the CTA, max 12 words, with no more than one ask.

Voice: [PASTE 3 REAL PARAGRAPHS THE FOUNDER WROTE]
Match this voice. Do not use emojis. Do not use the word "journey".
Stage 04 · Visual direction 
Using this slide JSON: [PASTE JSON]

Assign each slide one of four templates and write the layout note:
  T1 DARK HOOK     — full-bleed dark, huge serif headline, small kicker
  T2 NUMBERED      — light background, big numeral, headline + short body
  T3 PROOF         — dark again, one stat or quote, generous whitespace
  T4 BRAND CTA     — brand mark, coral CTA line, one action only

Brand tokens (never invent new ones):
  ink #12211C · paper #FBF8F2 · green #0E5A46 · coral #E8613F
  display: Georgia serif · ui: Segoe UI · radius: 20px
  spacing: 96px outer padding on a 1080x1350 canvas

Return a table: slide | template | layout note (max 12 words) |
image needed (yes/no) | image prompt if yes.
Alternate light and dark so the set has rhythm when swiped.

Handoff checklist

What a founder hands to a freelancer, or keeps for themselves. Nine minutes of setup that removes most of the back-and-forth.

01

Brand token sheet — 4 colours, 2 fonts, 3 spacing values. One page.

02

Four slide templates named T1–T4, so prompts can reference them.

03

Three voice samples — real paragraphs, not "our brand is friendly".

04

An idea inbox — one Notion database row per voice note, with a status field.

05

Export spec — 1080×1350 for Instagram, 1080×1080 for LinkedIn, PNG.

06

A rejection log — every post the founder rejected, and why. This is the training data.

Honest limits

Where this system breaks

A workflow pitch that claims no weaknesses is a workflow nobody has run. These are the failures I'd expect in the first month.

It will sound like AI by week three

The model converges on the same rhythm. Fix: refresh the voice samples every ten posts and keep a "banned phrases" list.

Design quality plateaus at "good enough"

It will not produce a stand-out visual. It produces a consistent, competent one — which is the actual goal for a founder, not a portfolio piece.

Facts still need a human

Any health, legal or financial claim must be sourced. The prompt marks [VERIFIED] items for a reason; skipping that step is how brands get corrected in public.

Automation drifts silently

An n8n node fails at 2am and nothing posts for a week. Fix: a daily check-in message that fires only when the queue is empty.

That's the system

The carousel above was assembled from a JSON array, not typed into Canva.

Slide copy, template choice and layout notes all came out of stage 03 and 04. The page you're reading renders them straight from that data — which is the proof that the handoff works.

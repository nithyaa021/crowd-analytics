What this submission itself is built with

Plain HTML, CSS and ES2020 JavaScript, written by hand. No React, no Tailwind CDN, no bundler, no external fonts. Total payload is a few hundred kilobytes, and the whole thing opens from file://.

LayerChoice and reason
Markup Semantic HTML5 — main, section, fieldset, details. Gets accessibility and browser behaviour for free instead of reimplementing it.
Styling Hand-written CSS with custom properties. A design system in ~450 lines beats a utility framework here because the point is to demonstrate design judgement, not class-name recall.
Interaction Vanilla JS, one IIFE per page. The only stateful piece is the discovery filter object and the carousel index — far too small to justify a framework.
Type Georgia (display) + Segoe UI (interface), both system-resident on Windows. Zero network requests and no layout shift.
Icons Inline SVG paths. No icon font, no sprite sheet, and they inherit colour via currentColor.

Why not Figma for the deliverable? A Figma file is a picture of an interface; it cannot demonstrate a filter that filters. Given a choice between a beautiful static frame and a slightly less beautiful working page, the brief's weighting of "technical execution" and "product thinking" favours the working page.

01 · Discovery MVP — production stack

If this were built for real rather than prototyped, this is what I'd ship.

ConcernRecommendation
Frontend Next.js on Vercel. Server-rendered provider pages matter for SEO — people search "vet near me", not "practo for animals".
Search Postgres with pg_trgm for fuzzy name matching, plus Meilisearch once listings pass ~5,000. Typo tolerance on clinic names is not optional.
Geo PostGIS for distance. "2.4 km away" must be a real query, not a stored number.
Maps Mapbox GL — generous free tier, and the styling can match the brand palette unlike Google's.
Data quality A verification queue with a 90-day re-check cron, and a correction table that auto-flags a listing after three reports.
Analytics PostHog (self-hostable) tracking search → card click → call tap. The call tap is the real conversion.

02 · Course landing page — stack

ConcernRecommendation
Build Same as above — Next.js. If the founder needs to edit copy weekly, Framer is the pragmatic alternative.
Forms Tally embedded, or a Next.js route handler writing to the CRM. Tally because it handles partial-submission tracking for free.
CRM Notion database to start (zero cost, founder already uses it), migrating to HubSpot Free at ~500 leads/month.
Messaging WhatsApp Business API via Interakt or Wati — the audience is in India and opens WhatsApp, not email.
Payments Razorpay, with the "pay after completion" model implemented as a deferred link sent at week three.
Analytics PostHog funnels on the five stages shown on the landing page; each stage is a named event, not a pageview.

03 · Content system — the automation stack

StageToolWhy
Capture Notion + Whisper Already open daily; local transcription is free and private.
Research Claude + Perplexity Structure from Claude, live citations from Perplexity. Never let a model invent a statistic.
Copy Claude Reliable JSON output and adherence to hard word limits.
Visual direction Claude + brand token sheet The token sheet is the anti-slop mechanism: fixed colours, fixed spacing.
Assembly Figma (variables + components) Editable in ten seconds per slide. Canva is the fallback if the founder edits without help.
Orchestration n8n (self-hosted) Free at volume, and the workflow survives a subscription lapse.
Review Human checklist Three questions, six minutes. Non-negotiable.
Publish Meta Business Suite + Buffer Native scheduling, no account risk from automation bots.

CTA map — every call to action and its job

A page with four equal CTAs has none. Each of these has one job and one placement, and the hierarchy is visible in the styling: coral solid for the primary, outline for the secondary, text-link for the tertiary.

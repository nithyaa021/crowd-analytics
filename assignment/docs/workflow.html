The carousel workflow, written out

The same pipeline as deliverable 03, but as an operating manual: what you do, what the machine does, how long it takes, what artefact comes out, and how it fails. Read this if you want to run it rather than look at it.

Overview

The system exists because the bottleneck on a founder's content is not ideas and not writing — it is layout. An idea takes two minutes; a decent eight-slide carousel takes two and a half hours, most of it spent nudging text boxes. This pipeline moves the mechanical 90% to machines and keeps the judgement with the founder.

One-time setup (about 90 minutes, once)

This is the part people skip, and then wonder why the output is inconsistent. Five artefacts, each of which is an input to a prompt later.

1. Brand token sheet

One page, four colours, two fonts, three spacing values, one radius. Example:

ink #12211C · paper #FBF8F2 · green #0E5A46 · coral #E8613F
Display: Georgia. UI: Segoe UI. Radius 20px. Outer padding 96px on 1080×1350.

Without this, the model invents a new palette by slide six and the set stops looking like one brand.

2. Four slide templates

Named, so prompts can reference them by name: T1 Dark Hook, T2 Numbered Point, T3 Proof, T4 Brand CTA. Build them once in Figma as one component with four variants.

3. Three voice samples

Three real paragraphs the founder actually wrote — a WhatsApp message, an email, a caption. Not "our brand voice is friendly and professional". The model needs rhythm, not adjectives.

4. An idea inbox

A Notion database with five fields: Idea, Status, Brief, Slide JSON, Published URL. One row per voice note. Status moves left to right; nothing is a blank page.

5. A rejection log

Every post the founder rejected and one line on why. This is the only real training data the system gets, and after a month it becomes the most useful document in the workspace.

Running it, once per post

Stage 1 — capture (3 min)

Record a voice note into Notion. Speak the idea messily; do not structure it. Run it through Whisper (free, local) or type three sentences if that's faster. Paste the transcript into the row's Idea field.

Stage 2 — research (6 min)

Paste the transcript into the research prompt from the workflow page. You get a brief with a claim, evidence marked [VERIFIED] or [OPINION], a counter-argument, and a number if one exists. Anything marked [VERIFIED] gets a Perplexity check before it survives.

The step people skip If the brief says "no defensible number available", that is the model doing its job. Do not ask it again until it produces a number. Rewrite the claim instead.

Stage 3 — copy (8 min)

Paste the brief and the three voice samples into the copy prompt. The output is a JSON array of eight objects — role, headline, body, kicker. Read it out loud. If a headline needs a comma to make sense, it is too long.

Stage 4 — visual direction (5 min)

Paste the JSON into the visual prompt with the token sheet. You get a table assigning each slide a template and a layout note. Check the alternation: dark, light, light, light, light, dark, dark, brand. If two darks sit together, the set loses its rhythm when swiped.

Stage 5 — assembly (10 min)

In Figma, one component with eight instances. Override the text from the JSON. Use variables for colour and spacing so a brand change updates all eight at once. If the founder will edit without help, use Canva with a locked brand kit instead.

Stage 6 — review and publish (6 min)

Three questions, out loud, in this order:

  1. Does slide 1 make someone stop scrolling, or does it describe the post?
  2. Is every claim one I'd defend to a vet, a customer, or a lawyer?
  3. Would I read this on my own phone, standing up, in traffic?

Fix anything that fails, export at 1080×1350 for Instagram and 1080×1080 for LinkedIn, schedule, done.

Why eight slides, and why those word limits

Eight is the short end of what Instagram allows (up to 20) and the long end of what people finish. Completion data across most accounts shows a cliff after eight. Fewer than six and the topic feels thin; more than ten and the last slides are seen by almost nobody.

  • Headline ≤ 9 words — fits two lines at 32px on a 1080-wide canvas without shrinking.
  • Body ≤ 22 words — roughly three lines at 18px, which is the point where people stop reading a caption-shaped paragraph.
  • Kicker ≤ 3 words, uppercase — a scanning aid, not a sentence.
  • CTA ≤ 12 words, one ask — two asks split the click.

How the n8n wiring works

The pipeline is runnable by hand from day one. n8n is added only when the founder is doing it three or more times a week, because automation of a process you have not yet run manually just automates confusion.

  1. Trigger — Notion database row changes status to "Ready".
  2. HTTP node — send the transcript to the research prompt via the Claude API.
  3. Code node — extract the brief, pass it to the copy prompt, parse the JSON response.
  4. HTTP node — send the JSON plus the token sheet to the visual prompt.
  5. Figma API node — or the Canva bulk-create endpoint — populate the eight frames.
  6. Notion node — write the design link back to the row and set status to "In review".
  7. Slack / WhatsApp node — notify the founder that a draft is ready.

There is deliberately no publish node. The final export and schedule stays manual.

Failure modes, and the fix for each

FailureFix
Output sounds like AI Refresh voice samples every ten posts; keep a banned-phrases list in the system prompt ("journey", "in today's world", "game-changer").
Slides overflow the frame The word limits exist for this. If a headline breaks, the model ignored the constraint — regenerate rather than shrink the type.
Set looks incoherent Template alternation was skipped. Enforce the dark/light rhythm in stage 04's prompt.
An invented statistic ships Because the [VERIFIED] check was skipped. This is the one failure with real reputational cost; automate a Perplexity lookup for every verified item.
n8n dies silently Daily heartbeat message that fires only when the queue is empty. Silence is the signal.
Founder stops using it Almost always because stage 1 became a form. Keep capture as a voice note; the moment it needs structure, the idea dies.
